# Save to Linkwell (Chrome extension)

A toolbar button that opens Linkwell's `/share` page for the tab you're on.

## Install it on your computer

1. Open `chrome://extensions` (also works in Edge, Brave and Arc).
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose this `extension` folder.
4. Click the puzzle piece in the toolbar and pin **Save to Linkwell**.

After changing a file here, click the reload arrow on the extension's card.

## Use it

On any page, click the Linkwell button or press **Alt+Shift+S**.
