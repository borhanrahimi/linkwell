Follow a request:

The four layers, and the one rule between them

Each layer only uses the ones below it. The build fails if a browser component imports lib/data.ts or db/, because both start with import "server-only".

app/

Routes only: pages, Server Actions (actions.ts) and API routes. The doors in from the internet.

components/

The interactive screens (React, "use client"): LinkManager, Home, the sidebar, cards, dragging.

lib/

Plain TypeScript. The rules (used on both sides), the database questions, safe fetching, sign-in, limits.

db/ · types/ · drizzle/

Table definitions, shared types, and the numbered SQL migrations (0000 to 0018). Committed, never edited.
